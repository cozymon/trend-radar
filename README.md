# Trend Radar

초보자용 Vercel 배포 패키지입니다.

## 가장 쉬운 배포 방법

1. 이 폴더 전체를 GitHub 새 저장소에 업로드합니다.
2. Vercel.com에 로그인합니다.
3. Add New → Project를 누릅니다.
4. GitHub 저장소를 선택합니다.
5. Framework Preset이 Next.js인지 확인합니다.
6. Deploy를 누릅니다.

배포 후 아래 주소도 확인하세요.

- /api/market-context
- /api/trend-signals

둘 다 JSON이 보이면 실제 API 연결이 된 것입니다.
